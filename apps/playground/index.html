03 / Share only what you mean to

Parsing and replay stay in this browser. There are no trace uploads, analytics, or remote imports. A share link contains the full compressed trace and fault scenario. Anyone with the link can read it. Remove tokens, prompts, user data and other secrets first. Do not use real private traces in a share link.

Reloading a share link loads its trace locally. Nothing is stored in localStorage. Clear removes this page's fragment, not copies of the link elsewhere.

Deterministic replay, not a live model. Start with synthetic data.
